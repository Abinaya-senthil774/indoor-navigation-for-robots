Algorithm 4: Junction Tag Placement (MILP)

Inputs:
  Visibility matrix V
  Candidate tag set C
  Robot poses P
  Junction locations J
  Current covered poses c
  Tag budget Njunc

Outputs:
  Junction tag set Tjunc
  Updated coverage vector c

1. For each junction j ∈ J
     Define pre-turn pose window Wj
       based on corridor width and turning geometry

2. Restrict candidate tags:
     Cj ← { t | ∃ i ∈ Wj such that V(i,t) = 1 }

3. Define binary decision variables:
     xt ∈ {0,1} ∀ t ∈ Cj

4. Define objective:
     Maximize total newly covered poses:
       max ∑t xt ⋅ ∑i (1 − c_i) V(i,t)

5. Subject to:
     (a) Pre-turn visibility:
         ∀ j ∈ J :
         ∑t xt ⋅ (∨i∈Wj V(i,t)) ≥ 1

     (b) Tag budget:
         ∑t xt ≤ Njunc

     (c) Binary constraints:
         xt ∈ {0,1}

6. Solve MILP → obtain xt*

7. Tjunc ← { t | xt* = 1 }

8. Update coverage:
     c ← c ∨ (∨t∈Tjunc V(:,t))

Return Tjunc, c
